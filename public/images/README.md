# Gambar lokal untuk item ID 4

Letakkan gambar kamu di folder ini dengan nama `developer.webp`. URL yang dikirim oleh API untuk item ID 4 adalah:

`http(s)://<host-yang-dipakai-untuk-API>/images/developer.webp`

Folder ini berada di bawah `public`, sehingga PHP built-in server menyajikan gambarnya langsung sebagai file statis. Jika memakai nama atau ekstensi lain, ubah path pada `src/items.php` agar sesuai.
